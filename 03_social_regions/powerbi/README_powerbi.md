# Дашборд в Power BI: пошаговая сборка

**Файл с данными:** `powerbi/regions_kz_powerbi.xlsx` — 5 готовых листов, ничего чистить не нужно.
**Что получится:** отчёт из 2 страниц (плюс необязательная третья), без связей между таблицами.
**Сохранить как:** `powerbi/regions_kz_dashboard.pbix`.

| Лист | Что в нём | Строк |
|---|---|---|
| `Регионы_2024` | 20 регионов, все показатели за 2024 г. и индекс качества жизни | 20 |
| `Неравенство` | коэффициенты вариации и разрыв по годам | 10 |
| `Доходы_динамика` | доход 16 сопоставимых единиц по годам | 160 |
| `Остатки_модели` | насколько доход выше или ниже, чем предсказывает ВРП (этап 6) | 16 |
| `Гипотезы` | итоги проверки H1–H5 (этап 7) | 5 |

---

## Шаг 1. Загрузка

1. **Главная → Получить данные → Книга Excel** → выберите `regions_kz_powerbi.xlsx`.
2. Отметьте все 5 листов → **Загрузить** (не «Преобразовать»).
3. Перейдите в **представление данных** (значок таблицы слева) и проверьте типы:
   - числовые столбцы должны быть числами (значок `123` или `1.2`), а не текстом (`ABC`);
   - у столбца **`Год`** в таблицах `Неравенство` и `Доходы_динамика`: **Средства работы со столбцами → Сводка → Не суммировать**. Иначе Power BI будет складывать годы.

## Шаг 2. Меры

Создайте в таблице `Регионы_2024` (правой кнопкой по таблице → **Создать меру**) по одной формуле за раз:

```DAX
Средний доход по стране =
DIVIDE(
    SUMX('Регионы_2024', 'Регионы_2024'[Доход на душу, тенге] * 'Регионы_2024'[Население]),
    SUM('Регионы_2024'[Население])
)
```
Доход, взвешенный по населению: Алматы с 2,2 млн жителей весит больше, чем Ұлытау с 0,2 млн.

```DAX
Регионов = COUNTROWS('Регионы_2024')
```

В таблице `Неравенство`:

```DAX
Разрыв 2024 = CALCULATE(MAX('Неравенство'[Разрыв max/min]), 'Неравенство'[Год] = 2024)
```
```DAX
Разрыв 2015 = CALCULATE(MAX('Неравенство'[Разрыв max/min]), 'Неравенство'[Год] = 2015)
```
```DAX
Изменение разрыва = [Разрыв 2024] - [Разрыв 2015]
```
```DAX
Неравенство 2024 = CALCULATE(MAX('Неравенство'[Коэф. вариации, %]), 'Неравенство'[Год] = 2024)
```

Формат: `Средний доход по стране` — целое число с разделителем тысяч; `Разрыв 2024` и `Изменение разрыва` — 1 знак после запятой.

## Шаг 3. Страница 1 «Регионы в 2024 году»

| Элемент | Визуал | Поля |
|---|---|---|
| Заголовок | Текстовое поле | «Качество жизни в регионах Казахстана, 2024» |
| 4 карточки сверху | Карточка | `Средний доход по стране`, `Разрыв 2024`, `Изменение разрыва`, `Неравенство 2024` |
| Фильтр | Срез | `Тип региона` (стиль «Плитка») |
| Рейтинг по доходу | Линейчатая диаграмма с накоплением | Ось Y: `Регион`, ось X: `Доход на душу, тенге`, Легенда: `Тип региона` |
| Индекс качества жизни | Линейчатая диаграмма | Ось Y: `Регион`, ось X: `Индекс качества жизни` |
| Таблица | Таблица | `Регион`, `Доход / ПМ`, `Бедность, %`, `Продолжительность жизни, лет`, `Врачи на 10 тыс.` |

Настройки:
- в обеих линейчатых диаграммах: **… → Сортировать по убыванию**, включите **Метки данных**;
- цвета легенды: Нефтегазовый — оранжевый `#EB6834`, Остальные — синий `#2A78D6`;
- подписи карточек переименуйте понятно: «Разрыв: богатый / бедный регион», «Изменение с 2015 г.», «Неравенство, %».

Срез по типу региона фильтрует только визуалы из таблицы `Регионы_2024`. Карточки с разрывом берутся из таблицы `Неравенство` и от среза не зависят — так и задумано, это показатели по всей стране.

## Шаг 4. Страница 2 «Динамика и модель»

| Элемент | Визуал | Поля |
|---|---|---|
| Неравенство по годам | График | Ось X: `Год`, ось Y: `Коэф. вариации, %`, `Коэф. вариации взвешенный, %`, `Коэф. вариации реальный, %` |
| Разрыв по годам | Гистограмма с группировкой | Ось X: `Год`, ось Y: `Разрыв max/min`, метки данных включены |
| Фильтр регионов | Срез | `Регион (сопоставимый)` из `Доходы_динамика`, стиль «Раскрывающийся», множественный выбор |
| Доход по годам | График | Ось X: `Год`, ось Y: `Доход на душу, тенге`, Легенда: `Регион (сопоставимый)` |
| Доход и экономика | Линейчатая диаграмма | Ось Y: `Регион (сопоставимый)`, ось X: `Доход относительно ВРП, %`, Легенда: `Нефтегазовый` |

Настройки:
- у графиков с годами: **Формат → Ось X → Тип: Категориальный**, чтобы были видны все годы;
- в срезе регионов заранее выберите 3–4 региона, например Алматы, Астану, Атыраускую и ЮКО, иначе график из 16 линий нечитаем;
- последнюю диаграмму отсортируйте по возрастанию значения.

Подписи под визуалами (текстовые поля):
- под неравенством: «Разрыв сокращается: коэффициент вариации 39,7% → 28,7%. С учётом населения с 2020 г. сближения нет»;
- под последней диаграммой: «Нефтегазовые ЗКО, Актюбинская и Атырауская получают на 6–12% меньше дохода, чем предсказывает их экономика».

## Шаг 5 (необязательно). Страница 3 «Гипотезы»

Один визуал **Таблица** со всеми столбцами листа `Гипотезы`. Включите перенос текста: **Формат → Значения → Перенос текста**.

## Шаг 6. Сохранение и скриншоты

1. **Файл → Сохранить как** → `powerbi/regions_kz_dashboard.pbix`.
2. Сделайте скриншот каждой страницы (Win + Shift + S) и сохраните в `images/` как `dashboard_page1.png`, `dashboard_page2.png`.
3. Добавьте их в README в раздел «Дашборд».

## Частые проблемы

| Что видно | Что сделать |
|---|---|
| На оси X года выглядят как 2 015, 2 016 | Год → Сводка: Не суммировать; формат столбца — без разделителя тысяч |
| В карточке огромное число вместо года | У столбца `Год` осталась сводка «Сумма» |
| Линейчатая диаграмма не сортируется | Нажмите «…» в углу визуала → Сортировать по → нужное поле |
| Цифры с точкой выглядят странно | Файл → Параметры → Региональные параметры: русский формат чисел, это только отображение |
